# INSANE VPN

Приватный доступ в интернет без границ. Высокая скорость, без логов, без лимитов по трафику.

## Download & Install

Подключение занимает пару минут — тариф и устройство выбираются прямо в боте.

- [Telegram-бот](https://t.me/InsaneVPN_bot) — оформление подписки, управление устройствами, конфиги для всех клиентов
- [Сайт](https://my.insanevpn.pro) — управление аккаунтом и подпиской через браузер

## Features

- Безлимитный трафик — без пакетов и ограничений по объёму
- До 20 устройств на одном аккаунте
- No logs — сервис не хранит журналы активности пользователей
- Маскировка трафика под обычный HTTPS — устойчивее к блокировкам, чем классический OpenVPN/IPsec
