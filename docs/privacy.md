# Privacy / No-logs

Сервис не ведёт журналы пользовательской активности: какие сайты посещались, что скачивалось, какой трафик проходил через сервер.

Что действительно нужно для работы сервиса:
- идентификатор аккаунта — для привязки подписки и устройств
- факт подключения устройства (без содержимого трафика) — для лимита на количество устройств

Оплата обрабатывается платёжным провайдером — сервис не хранит данные карт.
